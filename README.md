# Kiin Intelligence — LinkedIn Ads MCP

Hosted remote MCP that connects LinkedIn Ads (and optional CRM) to Claude, ChatGPT, Cursor, Grok, Copilot, and any MCP-capable client.

**This repository is a public stub.** The product is closed-source and runs at the remote URL below. There is no local install of the server binary.

## Remote MCP

- Streamable HTTP: `https://mcp.kiin.co/mcp`
- Base / OAuth: `https://mcp.kiin.co`
- Sign up / connect: https://web.kiin.co/signup

```json
{
  "mcpServers": {
    "kiin": {
      "url": "https://mcp.kiin.co/mcp"
    }
  }
}
```

OAuth only. No API keys or client secrets in config.

## What it does

- Read LinkedIn Ads performance with landing-page metrics, format-aware benchmarks, audits, and CRM-influenced pipeline
- Write with preview-then-confirm (pause, budgets, targeting, creatives, draft campaigns)

Docs: https://kiin.co/linkedin-ads-mcp
